The recurring section opener — small uppercase letterspaced label, usually bronze, sitting above a serif heading.

```jsx
<Eyebrow rule>Signature Collections</Eyebrow>
<Eyebrow tone="muted" center rule>The Atelier</Eyebrow>
<Eyebrow tone="on-dark">Trade &amp; Design Program</Eyebrow>
```

`tone`: accent (bronze, default), muted (greige), on-dark. `rule` adds a hairline; `center` balances rules on both sides.
