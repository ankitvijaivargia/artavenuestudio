Small uppercase label for cues like "New", "Made to Order", "Handcrafted", "Best Seller".

```jsx
<Badge variant="tint">New Arrival</Badge>
<Badge variant="outline">Made to Order</Badge>
<Badge variant="on-image">Handcrafted</Badge>
```

Variants: solid (charcoal), tint (bronze wash), outline (hairline), accent (bronze), on-image (frosted, for use over photography). `dot` adds a leading dot.
