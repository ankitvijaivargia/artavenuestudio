Hairline text field with an uppercase micro-label and quiet bronze focus. Use for trade enquiries, newsletter signup, and checkout.

```jsx
<Input label="Full name" placeholder="Jane Mehta" required />
<Input label="Project type" hint="Residential, hospitality, or commercial" />
<Input label="Notes" multiline placeholder="Tell us about your project" />
```

Pass `error` to show a terracotta error state, `multiline` for a textarea. Standard input attributes (`type`, `value`, `onChange`, `placeholder`) pass through.
